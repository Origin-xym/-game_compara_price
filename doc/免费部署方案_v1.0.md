### 3. 上公网前必须解决的 4 个硬约束

1. **Java 必须跑在能跑 JVM 的机器上** —— 静态托管（GitHub Pages、Cloudflare Pages）一行都跑不了后端。
2. **MySQL + Redis 必须外置** —— 免费云主机不会白送你这两个服务，要用第三方免费实例（有容量/连接数限制）。
3. **Epic / 小黑盒采集活不了** —— 依赖本机 Edge 窗口 + CDP 端口，云端没有桌面浏览器，headless 又被 Cloudflare 挡。上线后必须关闭，否则每次采集都失败写日志。
4. **免费层的通病** —— 休眠、冷启动 30~60 秒、512 MB 内存上限、每日命令数限流。

## 三、路线 A：本机 + Cloudflare Tunnel（推荐，零代码改动）

原理：`cloudflared.exe` 在本机主动连 Cloudflare 边缘节点，把 `localhost` 的端口映射成一个 `https://xxx.trycloudflare.com` 域名。**不需要公网 IP、不需要路由器端口映射、不需要备案**。代价是「本机关机/断网 = 网站打不开」。

### A1. 重新构建前端（必做）

`dist/` 里的产物可能与源码不同步，先重新打一次：

```powershell
cd D:\游戏比价平台\frontend
npm run build
```

产物在 `frontend/dist/`，正常会有 `index.html` + `assets/`。

### A2. 下载 cloudflared（不安装，绿色单文件）

> ⚠️ 实测踩坑（2026-11-27）：`Invoke-WebRequest` 直连 GitHub Releases 会卡死——本机 TLS 证书吊销校验直接失败（`CRYPT_E_NO_REVOCATION_CHECK`），表现为进度条停在 30 MB 不动、文件落成 0 字节。
> **必须走镜像**，实测 `gh-proxy.com` 可用（峰值 8.6 MB/s，55 MB 约 10 秒~3 分钟）。

```powershell
New-Item -ItemType Directory -Force "D:\游戏比价平台\tools" | Out-Null
curl.exe -L --ssl-no-revoke --retry 3 --retry-all-errors `
  -o "D:\游戏比价平台\tools\cloudflared.exe" `
  "https://gh-proxy.com/https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe"
```

下完必须验证（正确结果：大小 **55,470,800** 字节、签名 `Valid`、签名主体 `Cloudflare, Inc.`）：

```powershell
Get-Item "D:\游戏比价平台\tools\cloudflared.exe" | Select-Object Length
Get-AuthenticodeSignature "D:\游戏比价平台\tools\cloudflared.exe" | Select-Object Status, @{n='Signer';e={$_.SignerCertificate.Subject}}
& "D:\游戏比价平台\tools\cloudflared.exe" --version
```

备选镜像（按速度排序，都可用 `镜像前缀 + 原始 GitHub URL`）：`gh-proxy.com` > `ghfast.top` > `ghproxy.net`。若全部失败，检查是否开了代理/VPN 冲突。

### A3. 五分钟验证（先跑通再美化）

**第一步：放开 Vite 的 host 校验。** `frontend/vite.config.js`，在第 17 行 `port: 5173,` 下面**新增一行**：

```js
    allowedHosts: true,   // 允许通过 tunnel 域名访问（Vite 5.4.12+ 默认会拦非本机 Host）
```

保存后重启 `npm run dev`。

**第二步：起隧道**

```powershell

```

控制台会打印一行 `https://xxxx-xxxx.trycloudflare.com`，用手机 4G 流量打开这个地址，能看到游戏列表就说明链路通了。

> 这一步只是验证。Vite dev server 会把源码暴露出去、性能也一般，**正式对外用 A4**。

### A4. 正式版：Caddy 统一入口（前端 dist + `/api` 同源，最干净）

为什么需要它：前端 `baseURL` 是 `/api` 相对路径，5173 和 8081 是两个端口，直接暴露会 404。用 Caddy 把两者合成**一个端口、一个域名**，`/api/*` 转给后端，其余读 `dist`，同时自动处理 history 路由回退。**项目代码一行都不用改。**

**第一步：下载 Caddy**

```powershell
Invoke-WebRequest -Uri "https://caddyserver.com/api/download?os=windows&arch=amd64" -OutFile "D:\游戏比价平台\tools\caddy.exe"
```

**第二步：新建 `D:\游戏比价平台\tools\Caddyfile`**（注意路径用正斜杠）

```
:8090 {
    encode gzip

    handle /api/* {
        reverse_proxy 127.0.0.1:8081
    }

    handle {
        root * D:/游戏比价平台/frontend/dist
        try_files {path} /index.html
        file_server
    }
}
```

**第三步：启动**

```powershell
cd D:\游戏比价平台
.\tools\caddy.exe run --config .\tools\Caddyfile
```

浏览器打开 `http://localhost:8090`，前后端都通（列表能加载、点进详情能出价格卡片、登录能成功）。

**第四步：暴露 8090**

```powershell
.\tools\cloudflared.exe tunnel --url http://localhost:8090
```

拿到的 `https://xxx.trycloudflare.com` 就是可以直接发出去的正式链接。

> 小提示：同源访问时 Spring 不会判定为跨域，`WebMvcConfig` 里的 localhost 白名单**不用改**。若个别请求报 CORS，再按 B4 加域名。

### A5.（可选）换成固定域名

`trycloudflare.com` 的域名每次重启都会变，面试前一天重启就白发了。有自己域名（`.com` 年费约 50~100 元）后可固定：

```powershell
cd D:\游戏比价平台
.\tools\cloudflared.exe tunnel login
.\tools\cloudflared.exe tunnel create gameprice
.\tools\cloudflared.exe tunnel route dns gameprice price.你的域名.com
```

然后 `%USERPROFILE%\.cloudflared\config.yml`：

```yaml
tunnel: gameprice
credentials-file: C:/Users/creator/.cloudflared/<隧道ID>.json
ingress:
  - service: http://localhost:8090
```

启动改用：`.\tools\cloudflared.exe tunnel run gameprice`

### A6. 开机自启（可选，省得每次手动起）

任务计划程序里建两个「登录时运行」任务：

- `caddy.exe run --config D:\游戏比价平台\tools\Caddyfile`（起始目录 `D:\游戏比价平台`）
- `cloudflared.exe tunnel --url http://localhost:8090`

同时别忘了 MySQL 服务、`backend` jar、以及 `D:\Redis\redis-server.exe` 也要能自启。

### A7. A 路线验收

1. 手机 4G 打开隧道域名 → 列表页有数据、封面图正常
2. 点进详情 → 多平台价格卡片、走势图、史低标注正常
3. 注册 → 登录 → 收藏 / 取消收藏成功（说明 Redis 黑名单链路通）

## 四、路线 B：全云端免费（不依赖本机）

架构：`Cloudflare Pages`（前端）→ `Render Free`（后端 Docker）→ `TiDB Cloud Starter`（MySQL 兼容库）→ `Redis Cloud`（Redis）。全部有免费额度。

> ⚠️ 2026-11-27 实测：**Aiven 的免费 MySQL 计划已取消**，创建服务时最低档是「业余爱好者 ~25 美元/月」，没有任何 Free 选项。PlanetScale、Railway 的永久免费层也都已经没了。下面只列仍然真实可用的方案。

### B1. 建在线 MySQL

**首选 TiDB Cloud Starter（官方免费额度、不用绑卡、支持本项目排序规则）**

免费额度：每组织 5 个实例，每个 **5 GiB 行存 + 5000 万 RU/月**，官方明确 "No credit card is required to get started"。

1. 注册 https://tidbcloud.com → Clusters → **Create Cluster**（默认就是 Starter）→ 区域选 **Singapore / Tokyo**
2. 集群好了以后点 **Connect** → 选 Public → 点 **Generate Password**，把生成的密码立刻存下来（只显示一次）
3. 记下连接信息：`host`（形如 `gateway01.ap-southeast-1.prod.aws.tidbcloud.com`）、`port` **4000**、`user` 形如 **`3pTAoNNegb47Uc8.root`**（带集群前缀，必须连前缀一起用）、`database` = **`test`**
4. 配 IP 白名单：Connect 弹窗里点 **Configure IP Access List**，添加 `0.0.0.0/0`（Render 免费实例出口 IP 不固定，必须放开全部）
5. 导库（**先做下面这处改动，否则会报 `CREATE DATABASE` 拒绝**）

改动：`backend/src/main/resources/db/schema.sql` **第 7–9 行**（共享实例不允许自己建库，直接用平台给的 `test` 库）

```sql
-- 第 7 行  CREATE DATABASE IF NOT EXISTS game_compara_price
-- 第 8 行    DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
-- 第 9 行  USE game_compara_price;
```

把这三行整段注释掉（前面加 `-- `），其余 14 张表、1 个视图、15 处 `utf8mb4_0900_ai_ci` **全部不用动**——TiDB 官方 collation 列表里明确包含 `utf8mb4_0900_ai_ci`。

```powershell
mysql -h <host> -P 4000 -u "<集群前缀>.root" -D test --ssl-mode=VERIFY_IDENTITY `
  -p < "D:\游戏比价平台\backend\src\main\resources\db\schema.sql"
```

> TiDB Cloud Starter **强制 TLS**（只支持 TLS 1.2/1.3），JDBC 连接串必须带 `useSSL=true&requireSSL=true&sslMode=VERIFY_IDENTITY`，见 B3。
> 数据量参考：本项目 22 条游戏 + 价格记录，占用远小于 1 MB，5 GiB 额度基本用不完。

**备选 A：FreeDB 沙盒（零学习成本，但 30 天到期删库）**

https://freedb.tech → 免费给 2 个库、总共 **100 MB**、5 个并发连接。MySQL 8.0 原生支持 0900 排序规则，schema 只需同样注释掉第 7–9 行。
**关键限制：免费库 30 天后自动删除**，到期前需要重新建库导数据，或者升 $5/月 的 Pro 才能持久。

**备选 B：db4free.net（老牌免费 200 MB，速度慢、无 SLA）**

注册即得，MySQL 8，直连 3306。适合一次性演示，不适合长期挂。

> 明确不要选：Aiven（免费计划已取消，最低 25 美元/月）、PlanetScale（2024 已取消免费层）、Railway（只有试用额度）、Render 自带的数据库（只有 PostgreSQL，且免费库 30 天过期）。

## 五、两条路线通用：上线前必做

1. **换 JWT secret**（`application.yml` 第 47 行）：当前值已公开在 GitHub 上，谁都能伪造 token。至少改成 32 字节以上的随机串。
2. **数据库密码别进仓库**：`123456` 写死在 yml 里，虽然 `.gitignore` 没排除它。改环境变量兜底是一步到位。
3. **关闭 Epic / 小黑盒浏览器采集**（云端路线）：`application.yml` 第 69、71、74 行改 `false`，否则日志会被 `ensureReady` 失败刷屏。
4. **管理员账号自建**：`schema.sql` 无 INSERT，注册后 `UPDATE sys_user SET role = 2`。
5. **别放商业/侵权内容**：免费额度条款普遍禁止商用和高并发；封面图直接引用 Steam CDN，属于外链引用，问题不大。

## 六、常见报错对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面能开，列表一直转圈 | 前端请求走到了错的域名 / 8081 没起 | 检查 Caddy 的 `/api/*` 反代；或 `VITE_API_BASE` |
| 刷新 `/games/31` 变 404 | history 路由缺回退 | Caddy `try_files {path} /index.html`；Pages 加 `_redirects` |
| 浏览器报 CORS / preflight 失败 | 前后端不同域，白名单没加 | `WebMvcConfig.java` 第 79 行加域名 |
| 登录后所有受保护接口 401 | Redis 连不上（`AuthInterceptor` 第 83 行抛异常） | 核对 `REDIS_HOST` / 密码 / TLS；Redis Cloud 要填 `username: default` |
| `WeakKeyException` 启动失败 | JWT secret 少于 32 字节 | `application.yml` 第 47 行换长串 |
| `Too many connections` | Hikari 池大于免费库上限 | `maximum-pool-size` 降到 3 |
| 启动即 OOM / 反复重启 | 免费 512 MB 装不下默认堆 | `JAVA_TOOL_OPTIONS=-Xmx300m` |
| Epic 采集一直超时 / 403 | 云端无真实浏览器 | 关掉 `epic-browser-enabled` / `heybox-enabled`，只在本地采集后同步数据 |
| 首次访问要等 1 分钟 | 免费实例休眠后冷启动 | 正常现象，可加定时保活 |

## 七、结论

- 这个项目的**后端 + MySQL + Redis + 浏览器采集**四件套决定了它没法"丢给一个免费静态平台"就完事。
- **今天就能上线、且功能一个不少的做法是路线 A**（Cloudflare Tunnel + 本机现有环境），改动量为 0，唯一要求是本机保持开机联网。
- 如果目的是"链接长期有效、不看我电脑脸色"，走路线 B，接受「采集退化 + 冷启动」的代价。
