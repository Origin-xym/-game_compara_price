# 游戏跨平台比价系统 接口文档

| 项目 | 内容 |
|---|---|
| 文档编号 | GP-API-001 |
| 版本 | V1.0 |
| 编写日期 | 2026-11-25 |
| 对应代码 | `backend` 17 个控制器 / 45 个端点 |
| 配套文档 | `doc\软件开发文档_v1.0.md`（第 4 章总体设计、第 6 章详细设计、附录 B 错误码） |

## 0 通用约定

| 项 | 约定 |
|---|---|
| Base URL | `http://localhost:8081/api`（`context-path=/api`） |
| 数据格式 | 请求与响应均为 `application/json; charset=UTF-8` |
| 鉴权 | `Authorization: Bearer <token>`；公开接口无需 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（`LocalDate` 为 `yyyy-MM-dd`） |
| 金额 | 数值型，人民币单位元，两位小数 |
| 成功响应 | `{"code":0,"message":"成功","data":...}` |
| 失败响应 | `{"code":xxxxx,"message":"...","errors":{...}}`（`errors` 仅字段级校验时出现） |
| 分页响应 | `{"list":[...],"total":6,"page":1,"size":12,"totalPages":1,"hasMore":false}` |
| 分页参数 | `page` ≥ 1；`size` 上限 50（全局另有 200 兜底） |
| 空字段 | 全局 `non_null`，`null` 字段不输出 |
| 错误码 | 见主文档附录 B（400xx 参数 / 401xx 认证 / 403xx 权限 / 404xx 不存在 / 409xx 冲突 / 5xxxx 系统） |

**权限三档**

| 标记 | 含义 |
|---|---|
| 公开 | 无需 token |
| 登录 | 需有效 token（`/auth/me`、`/auth/logout`、收藏、提醒、通知） |
| 管理员 | 需 token 且 `role=2`（`/admin/**`） |

**运行期调试**：后端已引入 springdoc 2.6.0，启动后可访问 `/api/swagger-ui/index.html` 查看自动生成的接口页；但注解不全，字段说明以本文档为准。

# 1 认证（4 个）

## 1.1 `POST /auth/register` 注册

- 权限：公开
- 请求体：

```json
{ "username": "xym009", "password": "123456", "nickname": "小谢" }
```

| 字段 | 类型 | 必填 | 约束 |
|---|---|---|---|
| username | string | 是 | 非空，唯一 |
| password | string | 是 | 非空，后端 BCrypt 加密存储 |
| nickname | string | 否 | ≤ 32 字符 |

- 返回：`LoginVO`（注册成功即登录）

```json
{ "code": 0, "data": { "token": "eyJ...", "expiresAt": "2026-11-25 20:00:00",
  "user": { "id": 5, "username": "xym009", "nickname": "小谢", "role": 1 } } }
```

- 错误：`40902` 用户名已被注册；`40000` 参数校验失败（`errors` 含字段）
- 备注：注册后 `role` 固定为 1（普通用户），管理员需后台/手工设置。

## 1.2 `POST /auth/login` 登录

- 权限：公开
- 请求体：`{ "username": "...", "password": "..." }`
- 返回：`LoginVO`（同 1.1）
- 错误：

| 场景 | code | 说明 |
|---|---|---|
| 用户名/密码为空 | 40000 | `errors{username/password}` |
| 用户不存在 / 密码错误 | 40101 | 同码，防账号枚举 |
| 连续失败 5 次后 | 40302 | 锁定 15 分钟 |

- 备注：登录成功会清零 `failed_count` 并写 `last_login_time`。

## 1.3 `POST /auth/logout` 登出

- 权限：登录
- 请求体：无
- 返回：`{ "code": 0, "message": "已退出登录" }`
- 错误：`40100` 未登录；`40102` token 已过期
- 备注：把 token 的 `jti` 写入 Redis 黑名单，TTL = 剩余有效期；此后同一 token 请求返回 40103。

## 1.4 `GET /auth/me` 当前用户

- 权限：登录
- 参数：无
- 返回：

```json
{ "code": 0, "data": { "id": 5, "username": "xym009", "nickname": "小谢", "role": 1, "status": 1 } }
```

- 错误：`40100`、`40102`、`40103`

# 2 游戏（前台，6 个）

## 2.1 `GET /games` 游戏列表

- 权限：公开
- 参数（`@ModelAttribute` 绑定，全部可选除分页）：

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| page | long | 1 | 页码，≥1 |
| size | long | 12 | 每页条数，1～50 |
| keyword | string | — | ≤50 字符；匹配中文名、英文名、类型名（空格/大小写不敏感） |
| typeIds | long[] | — | 类型多选，`typeIds=1,2` 或重复参数 |
| platformIds | long[] | — | 平台多选（`EXISTS` 语义：该游戏在这些平台有有效价） |
| priceMin | decimal | — | 人民币最低价下限（含边界） |
| priceMax | decimal | — | 人民币最低价上限（含边界） |
| discountOnly | boolean | false | 只看有生效折扣的 |

- 返回：`PageResult<GameListItemVO>`

```json
{ "code": 0, "data": {
  "list": [{
    "id": 13, "name": "Grand Theft Auto V 增强版", "nameEn": "Grand Theft Auto V Enhanced",
    "coverUrl": "https://...", "gameTypeId": 2, "gameTypeName": "动作",
    "minPriceCny": 98.56, "platformCount": 2, "hasQuote": true,
    "hasDiscount": true, "maxDiscountRate": 56, "discountEndTime": "2026-12-01 00:00:00",
    "platforms": [{"platformId":10,"code":"EPIC","name":"Epic"},{"platformId":9,"code":"STEAM","name":"Steam"}]
  }],
  "total": 6, "page": 1, "size": 2, "totalPages": 3, "hasMore": true } }
```

- 错误：`40000`（`size` 超限、`priceMin > priceMax` 等）
- 备注：
  - `platforms` 按该平台人民币价升序排列（便宜的在前面）；
  - `minPriceCny` 与详情页“最低价”同口径，可直接对比。

## 2.2 `GET /games/{id}` 游戏详情

- 权限：公开
- 参数：`id`（path，游戏 ID）
- 返回：`GameDetailVO`

```json
{ "code": 0, "data": {
  "id": 9, "name": "文明6", "nameEn": "Sid Meier's Civilization VI", "gameTypeName": "策略",
  "releaseYear": 2016, "minPriceCny": 22.00, "hasQuote": true, "platformCount": 3,
  "lastUpdateTime": "2026-11-24 14:38:49",
  "platforms": [{
    "platformId": 9, "platformCode": "STEAM", "platformName": "Steam", "platformRegion": "CN",
    "currency": "CNY", "cnyAmount": 22.00, "originalAmount": 22.00, "rate": 1.0,
    "rateTime": "2026-11-24 14:38:49", "discountRate": 0, "discountActive": false,
    "recordedAt": "2026-11-24 14:38:49", "stale": false, "lowest": true, "hasPrice": true,
    "shopUrl": "https://store.steampowered.com/app/289070/", "linkAvailable": true,
    "riskLevel": 0, "riskReason": null, "purchasable": true,
    "historyLowCny": null, "lowestEverCny": 11.00, "lowestEverAt": "2026-11-20 11:04:19"
  }] } }
```

- 错误：`40401` 游戏不存在或已下架
- 备注：
  - `platforms` 中**有价的平台按价格升序**，占位卡排在最后；
  - 占位卡特征：`hasPrice=false`、`cnyAmount=null`、`externalId/storeUrl` 可能有值；
  - `lowest=true` 的且 `hasPrice=true` 的那一条即“当前最低”；
  - `stale=true` 表示最后更新超过 `app.price.stale-hours`（24h）；
  - `historyLowCny` 是官方史低（`historical_low`），`lowestEverCny` 是真实最低（`price_record` 聚合），两者含义不同。

## 2.3 `GET /games/{gameId}/price-history` 价格走势

- 权限：公开
- 参数：

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| gameId | path | — | 游戏 ID |
| days | int | 90 | 时间窗，归一化到 30/90/180/365 |
| platformId | long | — | 只看某平台（可选） |

- 返回：`PriceHistoryVO`

```json
{ "code": 0, "data": {
  "gameId": 1, "gameName": "赛博朋克 2077", "days": 30,
  "platforms": [
    { "platformId": 9, "platformCode": "STEAM", "platformName": "Steam", "currency": "CNY",
      "insufficient": false,
      "points": [
        {"recordedAt":"2026-11-20 11:04:19","cnyAmount":298.00,"isCurrent":0},
        {"recordedAt":"2026-11-24 14:38:49","cnyAmount":298.00,"isCurrent":1}
      ],
      "historyLowCny": null, "historyLowDate": null, "historyLowSource": null },
    { "platformId": 10, "platformCode": "EPIC", "platformName": "Epic", "points": [ ... ] }
  ] } }
```

- 错误：`40401`
- 备注：`insufficient=true` 表示该平台点数 < 2，前端只画点不连线；走势取 `status=1` 的全部采样点（含历史点与当前价）。

## 2.4 `GET /games/{gameId}/history-lows` 各平台历史低点

- 权限：公开
- 参数：`gameId`
- 返回：`List<PlatformTrendVO>`（结构同上，`points` 为历史低点序列）
- 错误：`40401`

## 2.5 `GET /game-types` 游戏类型

- 权限：公开
- 返回：`List<GameTypeVO>`

```json
{ "code": 0, "data": [ { "id": 1, "code": "ACTION", "name": "动作", "sortNo": 1 } ] }
```

## 2.6 `GET /platforms` 前台平台下拉

- 权限：公开
- 返回：`List<PlatformOptionVO>`，只含 `enabled=1` 的平台
- 备注：用于筛选栏与提醒弹窗的平台选择。

# 4 降价提醒（4 个，均需登录）

## 4.1 `POST /alerts` 新建提醒

- 权限：登录
- 请求体：

```json
{ "gameId": 9, "platformId": null, "type": 1, "targetPrice": 20.00 }
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| gameId | long | 是 | 游戏 ID（必须上架） |
| platformId | long | 否 | 指定平台；`null` 表示任一平台 |
| type | int | 是 | 1 目标价 / 2 跌至史低 / 3 任意降价 |
| targetPrice | decimal | type=1 必填 | > 0.01，且必须**严格低于**当前最低价 |

- 返回：`{ "code": 0, "data": 12, "message": "提醒已设置" }`（data 为规则 ID）
- 错误：

| 场景 | code |
|---|---|
| 游戏不存在/已下架 | 40401 |
| 目标价为空 | 40003 |
| 目标价 ≥ 当前最低价 | 40003 |
| type=2 但无官方史低 | 40000 |
| 同条件规则已存在 | 40906 |

- 备注：创建时把当前最低价写入 `baseline_price`，供 type=3 比较。

## 4.2 `GET /alerts` 我的提醒

- 权限：登录
- 返回：`List<AlertRuleVO>`

```json
{ "code": 0, "data": [{
  "id": 4, "gameId": 1, "gameName": "赛博朋克 2077", "coverUrl": "https://...",
  "platformId": 9, "platformName": "Steam", "type": 1, "typeText": "目标价",
  "targetPrice": 70.00, "baselinePrice": 143.93, "baselineTime": "2026-11-21 10:00:00",
  "status": 1, "lastFiredPrice": 61.92, "lastFiredTime": "2026-11-21 11:00:00",
  "createTime": "2026-11-21 10:00:00"
}] }
```

## 4.3 `PUT /alerts/{id}/status?status=` 启停

- 权限：登录
- 参数：`id`、`status`（1 启用 / 0 暂停）
- 返回：`{ "code": 0 }`
- 错误：`40000` status 非 0/1；`40300` 非本人规则

## 4.4 `DELETE /alerts/{id}` 删除提醒

- 权限：登录
- 返回：`{ "code": 0 }`
- 备注：逻辑删除（`alert_rule.deleted=1`）；非本人 403。

# 6 后台 · 游戏与链接（6 个，均需管理员）

## 6.1 `GET /admin/games` 游戏列表（含下架）

- 权限：管理员
- 参数：`page`（默认 1）、`size`（默认 10，≤50）、`keyword`（可选）
- 返回：`PageResult<Game>`（直接返回实体，含 `status`、`sortWeight`、时间戳）
- 备注：不分页过滤 `status`；按 `id DESC`。

## 6.2 `POST /admin/games` 新增游戏

- 权限：管理员
- 请求体：

```json
{ "name": "文明6", "nameEn": "Sid Meier's Civilization VI", "coverUrl": "https://...",
  "summary": "…", "gameTypeId": 3, "releaseYear": 2016, "sortWeight": 10 }
```

| 字段 | 必填 | 约束 |
|---|---|---|
| name | 是 | ≤200，唯一（去空格后） |
| nameEn | 否 | ≤200 |
| coverUrl | 否 | ≤500 |
| summary | 否 | ≤1000 |
| gameTypeId | 是 | 必须存在 |
| releaseYear | 否 | 1970～2100 |
| sortWeight | 否 | 默认 0 |

- 返回：`{ "code": 0, "data": 14, "message": "新增成功" }`
- 错误：`40901` 重名（`errors{name}`）；`40000` 类型不存在（`errors{gameTypeId}`）或字段校验失败

## 6.3 `PUT /admin/games/{id}` 编辑游戏

- 权限：管理员
- 请求体：同 6.2（全量字段）
- 返回：`{ "code": 0 }`
- 错误：`40401`；`40901`（仅改名时查重且排除自身）
- 备注：只改 `game` 表，价格历史、收藏、提醒均不受影响。

## 6.4 `PUT /admin/games/{id}/status?status=` 上下架

- 权限：管理员
- 参数：`status`（1 上架 / 0 下架）
- 返回：`{ "code": 0, "message": "已下架" }`
- 备注：下架后前台列表与详情均 40401；已有收藏仍保留但无法进详情。

## 6.5 `GET /admin/games/{gameId}/links` 各平台链接

- 权限：管理员
- 返回：`List<GamePlatformLinkVO>`（每个平台一行，含未关联平台）

```json
{ "code": 0, "data": [{
  "platformId": 9, "platformCode": "STEAM", "platformName": "Steam", "platformRegion": "CN",
  "externalId": "1091500", "storeUrl": null,
  "listed": 1, "effectiveUrl": "https://store.steampowered.com/app/1091500/?cc=cn"
}] }
```

- 备注：`effectiveUrl` 是最终生效链接（`storeUrl` 优先，否则模板 + `externalId`）。

## 6.6 `PUT /admin/games/{gameId}/links/{platformId}` 保存链接

- 权限：管理员
- 请求体：

```json
{ "externalId": "289070", "storeUrl": "https://store.steampowered.com/app/289070/", "listed": 1 }
```

| 字段 | 约束 |
|---|---|
| externalId | ≤100；Steam 为纯数字 appid，Epic 为 slug |
| storeUrl | ≤500；非空时优先于模板 |
| listed | 0/1 |

- 返回：`{ "code": 0 }`
- 错误：`40401` 游戏不存在；`40402` 平台不存在
- 备注：写入会记审计 `LINK_UPDATE`（仅 `storeUrl` 前后值）。

# 7 后台 · 平台与锁区风险（7 个，均需管理员）

## 7.1 `GET /admin/platforms` 平台列表

- 权限：管理员
- 返回：`List<AdminPlatformVO>`（不分页）

```json
{ "code": 0, "data": [{
  "id": 9, "code": "STEAM", "name": "Steam", "region": "CN", "currency": "CNY",
  "linkTemplate": "https://store.steampowered.com/app/{externalId}/?cc=cn",
  "dataSourceType": 1, "dataSourceTypeText": "官方 API",
  "apiReady": 1, "enabled": 1, "remark": null,
  "currentPriceCount": 6, "recordCount": 20, "hasHistory": true
}] }
```

- 备注：`currentPriceCount` / `recordCount` 每平台各查 2 次（N+1，已知 T-06）。

## 7.2 `POST /admin/platforms` 新增平台（含复活）

- 权限：管理员
- 请求体：

```json
{ "code": "STEAM", "name": "Steam", "region": "CN", "currency": "CNY",
  "linkTemplate": "https://store.steampowered.com/app/{externalId}/?cc=cn",
  "dataSourceType": 1, "apiReady": 1, "enabled": 1, "remark": null }
```

| 字段 | 必填 | 约束 |
|---|---|---|
| code | 是 | 自动大写；与 region 联合唯一 |
| name | 是 | ≤64 |
| region | 是 | 自动大写 |
| currency | 是 | 自动大写，3 位 |
| linkTemplate | 是 | ≤500，**必须含 `{externalId}`** |
| dataSourceType | 是 | 1/2/3；3 会强制 `apiReady=0` |
| apiReady | 否 | 0/1 |
| enabled | 否 | 默认 1 |
| remark | 否 | ≤200 |

- 返回：`{ "code": 0, "data": 9, "message": "平台已创建" }`
- 错误：`40000` 模板缺占位符 / 数据源类型非法；`40900` 同 code+region 已存在（未删除）
- 备注：若同 code+region 的平台曾被删除，走**复活**分支：保留原 ID、清 `deleted`、按请求覆盖字段，审计 `RESTORE_PLATFORM`。

## 7.3 `PUT /admin/platforms/{id}` 编辑平台

- 权限：管理员
- 请求体：同 7.2
- 返回：`{ "code": 0, "data": "<提示文本>", "message": "平台已保存" }`
- 备注：`data` 可能为空串；当币种或区域变更且该平台已有历史价格时，返回提示（历史价不改写）。
- 错误：`40402`；`40900` 冲突

## 7.4 `PUT /admin/platforms/{id}/status?status=` 启停平台

- 权限：管理员
- 返回：`{ "code": 0 }`
- 备注：禁用立即从最低价口径与前台消失；不删数据。

## 7.5 `DELETE /admin/platforms/{id}` 删除平台

- 权限：管理员
- 返回：`{ "code": 0, "data": "平台已删除（历史数据保留，可用同编码+区域重建恢复）" }`
- 备注：逻辑删除；`game_platform`、`price_record`、`historical_low` 全部保留。

## 7.6 `GET /admin/region-risks` 锁区风险列表

- 权限：管理员
- 参数：`platformId`（可选）
- 返回：`List<RegionRiskVO>`

## 7.7 `PUT /admin/region-risks` 新增/更新风险

- 权限：管理员
- 请求体：

```json
{ "platformId": 9, "region": "CN", "riskLevel": 0, "reason": "国区可直接购买", "source": "人工维护" }
```

| 字段 | 必填 | 约束 |
|---|---|---|
| platformId | 是 | 必须存在 |
| region | 是 | ≤16 |
| riskLevel | 是 | 0～3 |
| reason | 否 | ≤500 |
| source | 否 | ≤200 |

- 返回：`{ "code": 0 }`
- 备注：按 `platform_id + region` 幂等 upsert（`uk_platform_region`）。

# 8 后台 · 价格与史低（5 个，均需管理员）

## 8.1 `POST /admin/prices` 手工录入价格

- 权限：管理员
- 请求体：

```json
{ "gameId": 9, "platformId": 9, "currency": "CNY", "originalAmount": 22.00,
  "originalPrice": 199.00, "discountRate": 89, "discountEndTime": "2026-12-01 00:00:00",
  "remark": "官网促销" }
```

| 字段 | 必填 | 约束 |
|---|---|---|
| gameId / platformId | 是 | 必须存在 |
| currency | 是 | 必须等于平台币种 |
| originalAmount | 是 | > 0.01 |
| originalPrice | 否 | > 0.01；有折扣时必须 ≥ 现价 |
| discountRate | 否 | ≥ 0 |
| discountEndTime | 否 | 不得早于当前时间 |
| remark | 否 | ≤200（写入 `source_ref`） |

- 返回：`PriceRecordVO`
- 错误：`40002` 价格不合法；`40004` 折扣时间非法；`40401`/`40402`；`50301` 汇率缺失
- 备注：写入即成为当前价（旧当前价被归档）；`source_type=1`；`operator` 当前硬编码 `"admin"`（DEF-03）。

## 8.2 `GET /admin/prices/pending` 待确认队列

- 权限：管理员
- 参数：`page`（默认 1）、`size`（默认 20）
- 返回：`PageResult<PendingPriceVO>`

```json
{ "code": 0, "data": { "list": [{
  "id": 108, "gameId": 1, "gameName": "赛博朋克 2077", "platformId": 9, "platformName": "Steam",
  "currency": "CNY", "originalAmount": 367.08, "originalPrice": 367.08,
  "discountRate": 0, "cnyAmount": 367.08, "sourceType": 2,
  "sourceRef": "STEAM-CN-20261123-...", "operator": "collect:...",
  "recordedAt": "2026-11-23 15:00:00", "currentCny": 298.00, "diffPercent": 23.2,
  "createTime": "2026-11-23 15:00:00"
}] } }
```

## 8.3 `POST /admin/prices/{id}/approve` 通过

- 权限：管理员
- 返回：`{ "code": 0 }`
- 错误：`40905` 该记录已不在待确认状态；`40400`
- 备注：归档旧当前价 → 该行 `is_current=1, status=1, verified_by, verified_time`；审计 `APPROVE_PENDING_PRICE`。

## 8.4 `POST /admin/prices/{id}/reject` 驳回

- 权限：管理员
- 请求体（可选）：`{ "reason": "抓取异常，币种不符" }`
- 返回：`{ "code": 0 }`
- 备注：`status=3`，记录审核人；审计 `REJECT_PENDING_PRICE`。

## 8.5 `POST /admin/history-lows` 官方史低 upsert

- 权限：管理员
- 请求体：

```json
{ "gameId": 1, "platformId": 9, "lowAmount": 71.00, "currency": "CNY",
  "lowDate": "2024-06-28", "source": "manual", "sourceRef": null }
```

| 字段 | 必填 | 约束 |
|---|---|---|
| gameId / platformId | 是 | — |
| lowAmount | 是 | > 0.01 |
| currency | 是 | 3 位字母 |
| lowDate | 否 | 日期 |
| source | 是 | 数据源名；与 game+platform 组成唯一键 |
| sourceRef | 否 | 外部记录 ID |

- 返回：`{ "code": 0, "message": "已保存" }`
- 备注：按 `(game_id, platform_id, source)` 覆盖；换算 `low_cny` 使用当前汇率快照。

# 9 后台 · 采集与一致性（5 个，均需管理员）

## 9.1 `POST /admin/collect/run` 单平台采集

- 权限：管理员
- 参数：

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| platformId | long | 必填 | 平台 ID |
| scenario | string | NORMAL | 仅 Mock 源使用：NORMAL/DROP/SPIKE/PARSE_FAIL/EMPTY |

- 返回：`CollectResultVO`

```json
{ "code": 0, "data": {
  "batchNo": "STEAM-CN-20261125100000-1234", "platformId": 9, "platformName": "Steam",
  "total": 6, "successCount": 5, "queueCount": 0, "skipCount": 1, "failCount": 0,
  "status": 1, "errorMsg": null, "errors": [] } }
```

- 错误：

| 场景 | code |
|---|---|
| 平台不存在 | 40402 |
| `dataSourceType=3` / `apiReady=0` / 无采集器 | 40903 |
| 平台被禁用 | 40000 |

- 备注：`successCount=0` 且 `skipCount>0` 属于“同日去重全部跳过”，`status` 仍为 1。

## 9.2 `POST /admin/collect/run-all` 全平台采集

- 权限：管理员
- 参数：`scenario`（默认 NORMAL）
- 返回：`List<CollectResultVO>`（每个平台一条，失败平台单独带 `status=3`）
- 备注：串行执行；单平台异常不影响其他平台。

## 9.3 `GET /admin/collect/logs` 采集批次日志

- 权限：管理员
- 参数：`page`（默认 1）、`size`（默认 20）、`platformId`（可选）
- 返回：`PageResult<CollectTaskLogVO>`

```json
{ "code": 0, "data": { "list": [{
  "id": 67, "platformId": 9, "platformName": "Steam",
  "batchNo": "STEAM-CN-20261124155453-8987", "taskType": 1,
  "startTime": "2026-11-24 15:54:53", "endTime": "2026-11-24 15:55:01",
  "total": 6, "successCount": 0, "failCount": 0, "status": 1,
  "statusText": "成功", "errorMsg": null
}] } }
```

## 9.4 `GET /admin/consistency/check/{gameId}` 单游戏一致性自检

- 权限：管理员
- 返回：`ConsistencyVO`

```json
{ "code": 0, "data": {
  "gameId": 1, "gameName": "赛博朋克 2077", "checkedAt": "2026-11-25 10:00:00",
```

- 备注：`consistent=false` 时 `mismatches` 给出差异说明（如列表与详情最低价不一致）。

## 9.5 `GET /admin/consistency/scan` 全库抽样自检

- 权限：管理员
- 参数：`limit`（默认 20）
- 返回：`List<ConsistencyVO>`
- 备注：只扫前 `limit` 个游戏，非全量。
