|---|---|---|

## 1. 前置阻塞项（第 1 周必须启动，否则后续迭代排队）

这三件事有**外部等待时间**，不能等写到时才办：

| 编号 | 事项 | 占用 | 最晚截止 | 未办成的后果 |
|---|---|---|---|---|
| P-1 | **官方 API 能力探针**：逐平台确认能否拿到"地区零售价 + 折扣 + 截止时间"字段 | 0.5 人日 + 等待 | **W2 周五** | 若多数平台只给元数据不给价格，D7 白名单会几乎为空，M12 采集做完也没数据可采 |
| P-2 | 第三方史低数据源**授权申请 + 字段字典** | 2 人日 + 等待 | **W5 周五** | 阻塞迭代 5 的 M5 史低标注，AC-5.3 无法验收 |
| P-3 | 汇率 API 选型与密钥 | 1 人日 | W5 前 | 阻塞 AC-4.5/4.7，M4 卡片无人民币价 |

**另外一项不是技术依赖，但会反弹到代码**：Q5 的**一期平台白名单**必须在 **W1 周五**定下来，否则 AC-12.7（后台拦截无官方接口平台）写不出判定名单。

## 4. 关键路径与卡点

**关键路径**：P-1 API 探针 → 平台白名单（Q5）→ M12 采集 → 通知判定。
这条路径断在哪，里程碑 E 就整体后移，因为"自动采集 → 价格变化 → 触发提醒"是唯一有外部依赖的闭环。

**前 3 个最可能拖期的点**（按概率排）：

1. **P-1 结果不理想**（概率高）：官方 API 多数不给地区零售价 → D7 白名单缩到 1–2 个平台，"跨平台比价"卖点被削弱。建议 W2 探针出结果后**立刻复评 D4/D7**，而不是等到迭代 6 才发现。
2. **Q5 锁区规则未定**（概率中）：M6 锁区部分可能返工 1–2 人日，W14 余量正好吸收 1 条。
3. **P-2 授权没批下来**（概率中）：若 W5 拿不到凭据，M5 的史低标注只能先做"无标记"分支，AC-5.3 推迟到 W14。
